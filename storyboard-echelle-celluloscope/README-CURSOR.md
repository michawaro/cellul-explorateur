# Storyboard Celluloscope — animation clic par clic

- `frames-dialogues-1280x800/` : 17 images WebP numérotées avec le dialogue déjà intégré.
- `sources-1280x720/` : les mêmes plans sans bandeau de dialogue, pour afficher le texte en HTML/CSS.
- `storyboard.json` : ordre, nom du fichier, type de plan et dialogue associé.
- `animation-storyboard.webp` : aperçu animé automatique ; l’intégration finale doit avancer au clic.

Pour l’intégration, précharger l’image suivante, avancer d’un indice à chaque clic et conserver le ratio de l’image. Le JSON permet aussi d’animer séparément le dialogue pour une meilleure accessibilité.
