CELLULOSCOPE
===========

Installation
1. Décompresser le dossier complet.
2. Ouvrir index.html dans Chrome, Edge, Firefox ou Opera.
3. Aucune installation et aucune connexion Internet ne sont nécessaires.

Contenu pédagogique
- structures d'une cellule animale et végétale ;
- chloroplastes, paroi, membrane, cytoplasme et noyau ;
- définition d'un tissu ;
- comparaison bactérie / cellule animale ;
- estimation puis calcul d'une taille réelle avec un segment d'échelle ;
- ordre de grandeur du micromètre.

Le jeu fonctionne entièrement en local. Aucun nom, score ou autre donnée
n'est envoyé ni enregistré.
